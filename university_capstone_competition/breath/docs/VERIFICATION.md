# 검증 기록 — 2026-10-24

## 이번 변경

v3 ESP32 직접 DAC 제어. 웹 오디오 경로는 런타임에서 제거했습니다.
lib/audio/tone.ts와 해당 테스트는 v2 참고용으로만 남겨 두었습니다.
센서 두 개 연결 및 테스트 코딩 완료라는 팀 상황을 문서에 반영했습니다.

## 확인한 항목

- Next.js production build 성공.
- TypeScript typecheck 성공.
- Node 테스트: BLE 프레임/ACK/재부팅, 세션 취소, 출력 잠금, heartbeat, 오디오 없이 실제 장치 모드 제어.
- Python 분석 API 테스트 6개 통과.
- 로컬 브라우저: 최초 연결 모달 → 둘러보기 → 데모 연결 → 36개 구간 스윕 → 서버 분석 성공, 가상 피크 29Hz.
- ESP32 펌웨어: PlatformIO espressif32 6.9.0 / Arduino 2.0.17 / BNO08x 1.2.5 / ArduinoJson 7.2.1 컴파일 성공.
- 기본 출력 잠금 빌드 RAM 42,644 bytes, Flash 1,181,973 bytes (기본 앱 영역 90.2%).
- 실제 보드 업로드는 하지 않았습니다.

## 남아 있는 현장 검증

실제 GATT 연결/패킷 속도, 센서 주소·핀·샘플링률, INA226 전류 보정,
드라이버 입력 호환성, GPIO25 파형/진폭/정지, 타이머 유지 신호 만료,
BLE 해제/브라우저 종료/센서 오류 시 정지, 발열/정격/접촉 상태.
공개 HTTPS 배포, QR, 실제 Android 휴대폰에서의 발표 리허설.
iPhone 기본 브라우저 지원을 구현한 것은 아닙니다.
코드 검증 성공은 실물 안전성이나 의료 효과의 검증이 아닙니다.

펌웨어 빌드 중 임시 PlatformIO 설치가 변경했던 Python 의존성은 원래 버전으로 복원했고 pip check가 통과했습니다.
Windows의 긴 경로 제한으로 컴파일러 캐시는 짧은 임시 경로를 사용했습니다.
